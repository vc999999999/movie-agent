## 第一批已实现

- CLI `create --auto` 从提示词包准备扩展至完整自动流水线、渲染及粗剪输出。
- 自动流水线可接收刚创建、尚未分析的项目，自动分析并记录安全默认值。
- 镜头确认、提示词编译、单镜头渲染与自动流水线共用当前数据质量检查。校验角色、地点、场景引用、镜头 ID 唯一性、总时长及导演语法；错误阻止执行，警告保留。
- 每个流水线步骤及最终状态写入现有 SQLite 版本化产物，记录总耗时。直接 SDK 调用和后台调用均保存失败状态；重启后读取历史记录，未结束的记录显示中断。
- 新增回归测试，验证过期干净报告不能绕过检查、故障状态持久化、从一句话到可播放仿真成片。

## 建议执行次序

1. 可靠完成：本轮入口与检查修复 → 成功镜头复用与并发互斥 → 故障恢复演示。
2. 真正协作：独立质检职责 → 带具体错误的反馈 → 有限局部修复 → 修订证据展示。
3. 作品提升：叙事因果、参考资产一致性、声音与剪辑、真实媒体时长和解码检查。
4. 参赛证明：固定输入集、消融对照、盲评、一部完整作品和可复现操作记录。

## 验证边界

运行 `.venv/bin/python -m pytest -q`。测试默认启用 LLM 与 ComfyUI 仿真，FFmpeg 生成测试图和正弦音；测试证明工程链路可执行，不证明真实视频的叙事、人物一致性、声音或目标时长达标。原仿真镜头固定为两秒，尤其不能把分镜计划总时长当作成片时长。

持久化日志不等于持久化任务队列。重启后可以查询和重新启动，但当前尚不提供跨进程去重、任务自动接管或成功镜头免重渲染。质量检查本轮会阻止错误，不会自动修改电影内容。
